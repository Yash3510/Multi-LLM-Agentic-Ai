## Summary

The product name and mark reached every surface, the first-run screen was
rewritten for an industrial audience, and a dev-mode bug that kept deleting
the backend's static files was fixed.

## Why it changed

- The backend serves icons from its own static directory, so it was still
  handing out the upstream mark (`83b3689`).
- The first thing a new user saw was a farmhouse painting and suggestions
  about children's art and the Roman Empire (`b440633`).
- On every start the backend deleted its static directory and refilled it from
  a production build. From source there was no build, so icons returned 404
  (`5e86b9e`).

## Files changed

- `4ce/branding/make_assets.py`, `make_onboarding_bg.py`, `logo-mark.svg`, and the logo sources
- `static/static/*`, `backend/open_webui/static/*` (generated icons, splash, favicons)
- `src/lib/components/OnBoarding.svelte`
- `src/lib/i18n/locales/en-US/translation.json`
- `4ce/env.sovereign.example`

## Technical changes

- **Assets from a source** (`0bc689f`, `bdde6c1`). Every icon is generated by
  `make_assets.py` from committed artwork, not committed as opaque binaries.
  Since `bdde6c1` the mark is also a traced vector, giving an SVG favicon, bare
  marks for light and dark UI slots, and a PNG for Word reports.
- **Name through the interface** (`64f5bf1`). Names resolve from
  `WEBUI_NAME`, and the en-US locale overrides the remaining strings by value.
  The other locales keep their translations. The upstream changelog dialog no
  longer opens on version change. The above-50-users notice is deliberately
  left as it is.
- **First-run screen** (`b440633`, `69df476`). The copy states the claim
  ("Confidential work never leaves the premises"). The outbound documentation
  link is gone, and the starter prompts are the work the system is for. The
  welcome video plays once over a 15 KB still that also serves as the poster,
  and the mark sits top right.
- **Static directory** (`5e86b9e`). `FRONTEND_BUILD_DIR` pointed at the
  repository's `static/`, so the refill finds the 4CE assets. The two
  `custom.css` copies had drifted and were reconciled.

## Impact

Visual identity only. No agent behaviour changed.

# Frontend foundations decided

## What changed

- The first commits on `4ce-core`, the owned rebuild's branch, with its own history and no code from the earlier fork.
- ADR-0035 records the frontend foundations:
  - stack and exact versions
  - static serving from `4ce-server`
  - live updates that survive a reload
  - a fake API until the backend lands
  - six roles; desktop and tablet; English, built Hindi-ready; always "approve"
  - theme, accessibility, no glass, icons and quality gates
- ADR-0036 proposes how the licence gate treats MPL-2.0 build and test tools and the permissive licences Appendix A doesn't name.
- The design system page records the planned tokens, type, depth, motion, states, numbers, keyboard, tables, print and icon rules.
- The ADR index lists both records.

## Why

The master plan leaves the frontend's foundations open, and its choices disagree in places: icons, role names, the licence checker. Settling them before code means the first component is built to one standard. It also means today's inconsistencies (about 40 durations, 7 focus styles, meta text at 2.78:1) are not rebuilt.
